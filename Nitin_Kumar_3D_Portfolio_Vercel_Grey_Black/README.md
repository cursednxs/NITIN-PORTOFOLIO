# Nitin Kumar — 3D Portfolio

Grey/black 3D portfolio designed for direct deployment to Vercel.

## Deploy to Vercel
1. Extract this ZIP.
2. Create a new GitHub repository and upload all files/folders inside this directory.
3. On Vercel, choose "Add New Project" and import the repository.
4. Framework Preset: Other.
5. Build Command: leave empty.
6. Output Directory: leave empty.
7. Deploy.

You can also run the folder locally with VS Code + Live Server.

## Structure
- index.html
- style.css
- script.js
- vercel.json
- assets/profile.jpg
- docs/indian-politics-development.pdf
- docs/adani-hindenburg-case-study.pdf

The site is a static HTML/CSS/JS project. The 3D background uses Three.js from jsDelivr.
